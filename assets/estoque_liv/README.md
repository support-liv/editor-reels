# Estoque interno de vídeos da LIV

Material próprio da LIV (equipe, escritório, atendimento, processo) para usar como B-roll nos vídeos da LIV
— em especial quando a fala é sobre **processo, equipe, atendimento, análise de caso**. Tem prioridade sobre
banco de imagens externo nesses assuntos. **Só para a LIV** (não usar na Imigrar).

Os vídeos ficam no Git LFS (`git lfs install` uma vez no Mac; o `git pull` baixa normalmente).
Cada vídeo entra no `catalogo.json` com: arquivo, o que mostra, assuntos (palavras que a fala pode citar),
orientação (vertical/horizontal), duração e trechos bons.
